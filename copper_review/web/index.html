        Open from URL
        
    
    
    
        GitHub projects compile in your browser, including local imports and dependencies pinned in copper.mod / copper.lock. Private repositories need a token under Private repository access. Electrical IR and saved board scenes also open directly; open a board source and a board export one after the other to review both.
        
    
  
        
  
        Private repository access 
    
        Create a fine-grained token limited to the repositories you need, with Contents: Read-only permission. It is kept only in this tab until the tab closes and is sent only to api.github.com, never to other URLs or into exported reviews.
